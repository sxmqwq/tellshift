# Tellshift

**Read them. Stay unread. / 看穿对手，藏住自己。**

一个双向识别秘密策略的猜拳游戏。你与 bot 各持有一个隐藏身份：通过公开出招识别对方，同时用有限的伪装额度掩护自己。

线上地址：<https://sxmqwq.github.io/tellshift/>

## 运行与构建

无需安装依赖，使用 Node.js 22 或更新版本：

```sh
npm test
npm run build
python3 -m http.server 8080 --directory dist
```

打开 `http://localhost:8080`。所有资源使用相对路径，可以部署在 `/tellshift/` 子目录。

## 完整规则

- 一局最多 12 回合。双方独立随机获得身份，可以相同。
- 第一回合自由出招。之后，每种策略根据**已公开的真实出招**计算正常招式，伪装后的出招也会影响下一轮。
- 初始伪装额度 3 点，偏离正常招式消耗 1 点。每累计赢两手恢复 1 点，上限 3 点。先扣消耗，再结算补充，不能借用本轮可能获得的点数。
- **双方余额保密**，不公开哪一手使用了伪装。你能看到自己的余额与记录。
- 每轮 bot 先锁定出招，你选择后同时公开。从第 4 回合开始可以指认。
- 研判阶段，bot 先锁定是否指认及候选身份。你选择继续观察或提交指认后，双方同时结算。继续观察也可能触发 bot 的指认。
- 第 12 回合，双方必须指认。
- 只有一方猜中：正确者胜。只有一方指认且猜错：指认者负。双方同时猜中：比较猜拳胜场，更多者胜，持平则平局。双方同时猜错：平局。
- 结案后公开双方身份、指认、每轮正常招式、伪装与余额变化，供复盘。

| 身份 | 正常出招 |
| --- | --- |
| 固守型 / Anchor | 始终重复自己的第一手 |
| 轮转型 / Orbit | 克制自己上一手的招式 |
| 模仿型 / Echo | 复制对方上一手 |
| 反制型 / Counter | 克制对方上一手的招式 |
| 守胜型 / Keeper | 赢则重复自己上一手；输或平则按石头→布→剪刀→石头轮转 |

## Bot 的信息边界

`publicHistory()` 只传递 `{ player, bot }` 出招记录。`chooseBotAction()` 可以额外获取 bot 自己的身份、余额与难度，**不接收玩家身份、玩家真实余额、嫌疑笔记或当前未提交的出招**。`chooseBotGuess()` 只接收公开历史、难度和是否到达最终回合。

推理模块对五种候选身份分别回放伪装消耗、胜场及补充，排除额度不可能成立的身份，再根据遵循/偏离策略的行为权重排序。权重是启发式判断，并非校准后的真实概率。多个身份仍可行时，bot 可能猜错。

三个难度调整伪装频率与指认门槛，不通过读取隐藏信息提高难度。游戏随机种子和已经锁定的行动随进度保存在本机，以便刷新后继续同一局。

这是浏览器本地单人游戏，进度与 bot 的隐藏状态都在客户端。信息隔离约束的是 bot 决策模块；不提供防开发者工具作弊或服务器验证。没有账号、遥测、外部 API 或第三方资源请求。

## 操作与存档

- 鼠标/触摸选择出招，或使用 `1 / 2 / 3`；按 Enter 锁定。
- 点击嫌疑档案标记准备指认的身份，旁边的 × 仅手动划除，不影响 bot。
- 进度、嫌疑笔记和本机战绩使用带版本的 localStorage 保存。刷新保留已经锁定的 bot 行动；损坏或不兼容的存档会重置。
- 中途重新开始需要确认，不计入输赢。结束后可选择下局难度。
- 支持小屏布局、键盘焦点、原生模态框与减少动效设置。

## GitHub Pages

`.github/workflows/pages.yml` 在 `main` 推送后运行规则测试、构建静态资源，再部署 `dist/`。不需要仓库外的源码副本或个人主页仓库改动。

首次部署前，仓库 **Settings → Pages → Build and deployment → Source** 需要设为 **GitHub Actions**。如果仓库尚未启用 Pages，GitHub 要求仓库管理员完成这项设置；工作流默认的 `GITHUB_TOKEN` 不能代为首次创建站点。
